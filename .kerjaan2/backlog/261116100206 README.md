## Background

The package is used from another project and may be published. A newcomer needs a short page that says what Skeleto does, what it deliberately leaves out, and how to use it. The examples must not drift from the real behaviour.

## Request

Write a short `README.md` in English covering: what Skeleto does and what it deliberately does not do (`CLAUDE.md` section 2); an example of `@Config`, `@Action` and `@Wrapper` with `ordinal`; additional markers and the list of allowed names; starting it and reading the container; the table of which kind may depend on which; and that the application must run under a TypeScript-capable runtime because its `.ts` files are imported as they are. No controller, request or response examples.

## Done when

- [ ] The README covers each of the topics above and reads top to bottom in a few minutes.
- [ ] Every code example in the README is exercised by a test that takes the example from the README file itself (not a hand-kept copy) and starts it successfully, so an edit that breaks an example fails the tests.
- [ ] That test also shows the documented wrapper order and the additional markers in the container metadata.
- [ ] The README does not mention `readTypeArguments`, `@Controller`, `@RequestPart` or payloads.
- [ ] (owner) The README reads clearly to someone who has never seen the project.
